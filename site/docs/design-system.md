# Design system: engineering document

Static HTML and CSS, generated by `npm run build`. The page reads like mission documentation: a strict grid, type that does the work,
little colour, data and captions before decoration. See `design-cleanup.md` for what was removed and why.

## Fonts
Space Grotesk (headings and text) and JetBrains Mono (labels, numbers, buttons), self-hosted in `assets/fonts/`, SIL OFL 1.1.

## Tokens (`assets/css/tokens.css`)
- Colour: `--bg #0b1628`, `--frame`, `--line`, `--hover`, `--fg`, `--soft` (neutral secondary text), `--muted`, `--accent #ff8c1a` (actions, facts), `--found`, `--gap`, `--none`, `--nohaz`. Status colours always carry a text label.
- Type: `--font`, `--mono`, `--fs-xs` to `--fs-h1`, `--track-label`, `--measure`.
- Space and shape: `--gutter`, `--wrap`, `--space-1` to `--space-6`, `--radius` (2px). No pills, no shadows, no gradients, no blur.

## Classes
- Structure: `.scene` (a ruled section), `.scene--short`, `.scene__inner`, `.scene__head`, `.slab` (a flat panel with a 1px rule).
- Text: `.eyebrow` (mono caps), `.lead`, `.small`, `.mono`, `.beat__mark` (the quiet line that says a scene is illustrative or a concept).
- Actions: `.btn`, `.btn--primary`, `.actions`.
- Evidence: `.fact` is a sentence backed by evidence; `evidence.js` adds a tooltip with the verbatim quote and links to the source page and document.

## Data attributes
- `data-evidence="id1 id2"`: marks a fact. `evidence.js` loads `data/evidence.json`, numbers the sources and fills `<ol data-evidence-list>`.
- `data-illustrative`, `data-concept`: kept on the text; the gates read them. They show as a quiet line or a dotted underline, not as a badge.
- `data-computed`: text rendered unchanged from a data file.

## Custom elements
`<figure-host name="...">` loads `assets/figures/<name>/figure.{html,css,js}`. `ui-sdk` web components are still loaded for the interactive figures.
