# Fonts

Both files are self-hosted woff2 subsets (latin, latin-ext, variable weight) from the Fontsource packages
`@fontsource-variable/space-grotesk` and `@fontsource-variable/jetbrains-mono`. Both fonts are the ones the
team's demo video uses.

| Font | Use | Author | License |
|---|---|---|---|
| Space Grotesk | headings and text | Florian Karsten | SIL Open Font License 1.1 (`OFL-space-grotesk.txt`) |
| JetBrains Mono | labels, numbers, buttons | JetBrains | SIL Open Font License 1.1 (`OFL-jetbrains-mono.txt`) |

They are loaded by the `@font-face` rules at the top of `assets/css/tokens.css`.
